# 營養科戰情室（Firebase 版）

營養科的任務、出勤、請假、業務量與工作成就管理系統。網頁放在 GitHub Pages，資料存在 Firebase（Google 的雲端資料庫），同仁用院內信箱收登入連結即可使用，不需要密碼。

網址：https://yht5582-source.github.io/CND-task-/

## 一次性設定（約 10–15 分鐘，由主任操作）

### 1. 建立 Firebase 專案
1. 用 Google 帳號登入 <https://console.firebase.google.com>，按「新增專案」。
2. 專案名稱例如 `cnd-task`，Google Analytics 可關閉，建立。

### 2. 建立網頁應用程式並取得設定
1. 專案首頁按 `</>`（網頁）圖示，應用程式暱稱填 `戰情室`，不需勾選 Hosting，註冊。
2. 畫面會出現一段 `const firebaseConfig = { apiKey: ..., ... }`，把這幾個值填進本儲存庫的 `firebase-config.js`（或直接貼給協助設定的人）。

### 3. 開啟信箱連結登入
1. 左側「建構 → Authentication」→「開始使用」。
2. 「登入方式」→「電子郵件/密碼」→ 開啟 **電子郵件/密碼** 與 **電子郵件連結（無密碼登入）** 兩個開關 → 儲存。
3. 「設定 → 授權網域」→「新增網域」→ 填 `yht5582-source.github.io`。

### 4. 建立資料庫並貼上安全規則
1. 左側「建構 → Firestore Database」→「建立資料庫」→ 位置選 `asia-east1 (台灣)` → 以**正式版模式**建立。
2. 切到「規則」分頁，把本儲存庫 `firestore.rules` 全部內容貼上，並把 `DIRECTOR_EMAIL` 改成主任登入用的信箱（全小寫），按「發布」。

### 5. 第一次登入
1. 開啟網址，輸入主任信箱，收信點登入連結。
2. 看到「尚未開通」時，按下方「我是主任，進行首次設定」。
3. 在「首次設定」貼上人員名單（每行：`姓名 <email>`），選擇組長，按「建立初始資料」。
4. 完成後，名單上每位同仁都可以用自己的信箱登入。

## 身分與權限

| 身分 | 設定方式 | 可以做的事 |
|---|---|---|
| 主任 | 安全規則中的 `DIRECTOR_EMAIL` | 全部功能 |
| 組長 | 人員名單職稱「組長」 | 安排出勤、核准請假、指派／刪除任務、管理人員名單 |
| 營養師 | 人員名單職稱「營養師」 | 提出／認領任務、更新自己任務進度與成果、登錄自己的業務量、申請請假 |

權限由 `firestore.rules` 在伺服器端把關。人員填了「離職日」後，登入權限自動停用。

## 檔案
- `index.html`：整個網頁程式
- `firebase-config.js`：Firebase 專案設定（公開資訊）
- `firestore.rules`：資料庫安全規則（貼到 Firebase 主控台，不會自動套用）

本儲存庫為公開，程式碼內不含任何人員姓名或信箱；所有資料只存在 Firebase。
